My bachelor project, carried out in collaboration with Limbo, is Limbo Search, a search package that Limbo builds into Umbraco websites. On viborg.dk, about 15% of searches returned no results, often because users misspelled their queries. I built a lexical fallback in C# on .NET 10 that corrects misspellings using Levenshtein distance, and I added Umbraco.AI.Search with OpenAI embeddings so that full-sentence questions also find the right page. Semantic search was strong on its own, but its relevance cutoff was too blunt, so I set it to 0.4. Combining semantic search with the lexical fallback gave 12 out of 12 correct answers with no false positives. The test set was small, six synthetic pages, so the result shows that the approach works, not its quality at scale. That is exactly what I would like to keep working on.
